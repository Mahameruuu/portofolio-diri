Mengenal Saya Lebih Dekat

Saya adalah lulusan S1 Teknik Informatika yang memiliki ketertarikan kuat pada Backend Development. Bagi saya, bagian terpenting dari sebuah aplikasi adalah bagaimana data diproses, disimpan, dan dikirimkan secara aman di balik layar.

Saya juga menggunakan Git untuk mencatat alur kode dan Docker agar lingkungan pengembangan tetap teratur dan stabil. Saya senang memecahkan masalah seputar alur data, autentikasi pengguna, dan memastikan API dapat terhubung dengan baik ke aplikasi web maupun mobile.
